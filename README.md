# pag_Itec

Interactive 3D explorer for ITEC Río Cuarto. Drive a robot through a simplified building with one classroom per academic program.

Stack: Vite, TypeScript, Three.js, cannon-es.

## Run

```
npm install
npm run dev
```

## Controls

WASD or arrows to move, R to reset. Pick one of four visual styles (Original, Low-Poly, Voxel, Cinemático) from the selector in the top-left corner.
